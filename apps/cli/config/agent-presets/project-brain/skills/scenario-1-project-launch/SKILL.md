# 场景1：一句话启动一个项目

项目智脑 preset 的浏览器端演示模式会拦截普通输入，并用共享的“智慧园区建设项目”资料集渲染项目导入初始化方案和右侧项目方案编辑器。该资料集包含项目、任务、会议、风险与知识资料；结构化说明见同目录 `demo-data.json`。编辑器只在用户点击“编辑项目方案”后打开；提交批量调整会保留历史对话，并让演示模型流式输出修订后的方案。该流程不读取文件内容、不创建本地项目目录、不调用 visualize，也不生成 Word、Excel 或 Markdown 文件。

如果输入没有被浏览器 demo 接管，模型只做兜底说明：

- 告诉用户当前「项目智脑」日常模式应在 Web/桌面会话中使用。
- 不要探索工作区、不要创建文件、不要调用文档生成脚本。
- 不要展示工具调用过程。

固定演示含义：

- 创建结果代表独立「项目智脑」平台中的项目初始化完成。开始演示时会关闭平台模拟数据，确认执行完成后再开启模拟数据。
- 上传资料只作为浏览器文件元信息参与展示，文件内容不会被读取或上传。
- 用户可以调整项目基础信息、阶段、任务、风险和知识目录；日期通过表单选择，结构化调整会以可读摘要进入对话，载荷不会显示在聊天记录中。
- 编辑器打开后占用加宽的右侧主栏，保留聊天历史以便用户对照方案；编辑入口之外不自动打开该区域。
