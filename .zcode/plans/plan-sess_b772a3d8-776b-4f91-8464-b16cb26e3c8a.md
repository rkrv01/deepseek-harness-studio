# 项目智脑全量英文适配（跟随应用语言设置）

## 架构（语言传递链路）
- **语言来源**：应用设置里的 Language（`locale.preference`，中文/English），切换后全局生效
- **client UI**：`ctx.locale.register(NS, {zh, en})` 双语字典，组件 `t()` 翻译（仓库标准模式）
- **demo adapter（host 端生成 AI 回复）**：从 `ctx.settings` 读 `locale.preference`，用对应语言生成场景正文——与 client 侧共享同一份「双语数据 + 语言选择器」
- **切换行为**：语言切换即时生效（新场景对话用新语言；历史消息保持原语言）

## 数据层改造（共享双语数据）
`@deepseek-ai/dsh-client-ui-project-brain/scenario`（client 与 host 共用）：
1. **`scenarios.json`**：每个场景的 `title/suggestion/thinking/review.*/execution.*` 加英文；`triggers` 加英文关键词（`matchProjectBrainScenario` 按语言选 triggers）
2. **`project-data.ts`**：`PROJECT_BRAIN_PLAN` / `MEETING_ANALYSIS_MOCK` / `PROJECT_BRAIN_COPILOT_DEMO` / `PROJECT_BRAIN_MY_DAY_DEMO` / `MEETING_MINUTES_TEXT` 全部双语化（新增英文副本或 `{zh,en}` 结构）
3. **`scenario.ts`（demo adapter 回复模板）**：launch-plan / meeting-analysis / handoff / executive-briefing / 各类 receipt / fallback 模板全部按语言输出

## UI 组件双语化（client，注册 projectBrain NS 字典）
- `ProjectBrainMessageDock.tsx`：5 个场景快捷按钮 + 「可以直接开始」+ 初始化进度/同步进度/项目就绪卡
- `ProjectBrainWorkbench.tsx`：编辑工作台全部标签/按钮/提示
- `ProjectBrainScenarioSurface.tsx`：托管看板/今日工作台全部文案（含 overviewTone 中文正则 → 改标记驱动）
- `ProjectBrainTurnTail.tsx`：确认卡/决策回执/材料选择/执行进度/结果卡
- `PlatformSettingsSection.tsx`、`DeveloperModeGate.tsx`、`state.ts`（NEXT_ACTIONS/修订摘要/isLaunchPrompt 正则）、`client/index.ts`（settings label / user prompt 生成）
- 模拟上传文件名、汇报材料文件名保持中文（它们是演示材料本身的文件名）

## 关键改动点
1. `demo adapter apply()`：`ctx.settings` 读 `locale.preference` → 传给 `resolveProjectBrainReply(prompt, locale)` 和 stream 状态文案
2. `matchProjectBrainScenario(text, locale)`：按语言匹配 triggers（`isLaunchPrompt` 同样双语）
3. `TurnTail.tsx` 的 marker 判定（`项目导入与初始化方案：` 等中文子串）→ 改为依赖 ASCII 的 `<!-- project-brain:* -->` 标记（不依赖语言）
4. `scenario-registry.ts`：`projectBrainScenario(id, locale)` 按语言返回定义
