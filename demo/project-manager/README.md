# 项目启动 Agent Demo

## 使用方式

1. 启动服务后，在对话中**选择"项目启动 Agent"预设**
2. 输入指令，例如："帮我启动智慧园区建设项目"
3. 上传示例资料（可拖拽或粘贴文件）
4. Agent 自动分析资料并生成项目方案
5. 确认后，Agent 创建项目目录结构

## 示例资料

本目录包含以下示例文件，可用于演示：

| 文件 | 用途 |
|---|---|
| `立项文件.md` | 项目立项审批文件，包含项目背景、目标、组织、预算 |
| `技术方案.md` | 项目建设技术方案，包含架构设计、功能描述、实施计划 |

## 演示效果

演示时重点展示：

1. **上传资料** → 用户拖入文件，Agent 开始阅读
2. **自动分析** → Agent 提取项目名称、目标、范围、组织、风险等
3. **生成方案** → Agent 展示项目规划、阶段划分、任务分解、风险清单
4. **确认创建** → 用户确认后，Agent 创建完整的项目目录结构
5. **后续问答** → 用户可以继续追问项目细节
