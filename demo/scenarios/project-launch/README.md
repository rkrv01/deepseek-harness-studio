# 场景1：项目启动

## 演示指令

```
帮我启动智慧园区建设项目，资料在 demo/scenarios/project-launch/input/ 中
```

## 输入材料

| 文件 | 用途 | 格式 |
|------|------|------|
| `input/立项文件.md` | 项目立项审批文件，含背景、目标、组织、预算 | Markdown |
| `input/技术方案.md` | 技术方案，含架构设计、功能描述、实施计划 | Markdown |

## 预期输出

Agent 应依次产出以下内容：

### 1. 项目信息分析摘要
展示从文档中提取的关键信息，以表格形式呈现。

### 2. 项目启动方案（与用户确认）
包含以下板块，每个板块用 Emoji 标题标识：
- 📋 项目信息卡
- 🎯 项目目标
- 📊 项目阶段规划（含 Mermaid 流程图）
- 📝 任务分解
- ⚠️ 初始风险识别
- 📁 项目知识空间

### 3. 项目文件创建
用户确认后创建以下文件：

| 文件 | 内容 |
|------|------|
| `README.md` | 项目总览 |
| `plan.md` | 项目计划与里程碑 |
| `tasks.md` | 任务清单 |
| `risks.md` | 风险登记册 |
| `project-data.json` | 结构化项目数据 |

## 核对清单

- [ ] Agent 读取了输入目录中的文档
- [ ] 项目信息卡以表格形式展示
- [ ] 阶段规划含 Mermaid 流程图
- [ ] 任务分解含负责人和工期
- [ ] 风险清单含类型和应对措施
- [ ] 用户确认环节存在
- [ ] 确认后创建了项目目录和文件
- [ ] `project-data.json` 格式正确
