# 项目智脑 — 场景总览

## 预设信息

| 项目 | 内容 |
|------|------|
| 预设名称 | 项目智脑 |
| 预设文件 | `apps/cli/config/agent-presets/project-brain/` |
| 技能文件 | `skills/scenario-1-project-launch.md`（场景1） |
| 适用场景 | 项目启动、项目规划、项目跟踪、项目复盘等 |

## 使用方式

1. 启动服务后，选择"项目智脑"预设
2. 输入场景对应的指令，如"帮我启动智慧园区建设项目"
3. Agent 根据 skill 指令执行对应场景的工作流
4. 人工核对输出结果

## 演示核对流程

每个场景的 `expected-output/` 目录中存放了预期输出模板，演示后逐项核对：
1. 输出格式是否符合预期
2. 输出内容是否完整
3. 是否包含所有必要元素（表格、图表、代码块等）
